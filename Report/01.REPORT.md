## 1. 요약

이번 세션은 **MomTest 방식의 고객 발견(Discovery)** 과 **TDD용 계약 추출**을 두 축으로 진행했다.

1. **1인 가구 프리미엄 밀키트** 가설 검증용 MomTest 질문 6개 작성, 30대 1인 가구 페르소나 인터뷰 시뮬레이션, 응답에 대한 비즈니스 분석(가짜 칭찬·진짜 고통·가설 폐기/수정) 및 INV/E 계약 도출.
2. **장바구니 할인 계산기** 인터뷰 메모(소계·문턱 10%·VIP 5%·CS 버그)를 MomTest→TDD 절차(Step 1~7)로 변환하여 **INV-1~4, E-1~2, AC-1~2** 및 **OOS-1~8** 확정.

코드·테스트 파일은 아직 생성하지 않았으며, 다음 RED 사이클의 입력 명세로 사용 가능하다.

## 2. 핵심 결정·산출물

### 2.1 밀키트 도메인 (페르소나 인터뷰 1건)

| 구분 | 결론 |
|------|------|
| 위험 시그널 | 미래 구매 약속·칭찬 없음. 다만 "가끔 요리" 자기 합리화 vs 실제 배달 5/7일 불일치 |
| 진짜 고통 | 메뉴 결정 피로, 배달 대기 30~40분, 1인분 잔반·재료 폐기, 조리·치우기 비효율 |
| 폐기 가설 | 건강 집밥 니즈, 프리미엄→요리 증가, 식비 절감 포지셔닝 |
| 살아 있는 가설 | 결정 없음, 1인 1끼, 배달 대기보다 빠른 식사, 최소 치우기 |

주요 계약 예: INV-1(메뉴 결정 0단계), INV-2(1인 1끼·잔반 없음), INV-3(20분 이내), E-1(1인분 초과 기본 제공 금지), E-2(조리+치우기 > 식사 시간 금지).

### 2.2 장바구니 할인 도메인 (인터뷰 메모)

| ID | 계약 요약 | 근거 |
|----|-----------|------|
| INV-1 | `subtotal = sum(price × qty)` | #1107, #1042, 03-12 예시 |
| INV-2 | `subtotal > 50_000` → `round(subtotal × 0.9)` | "5만 원 넘으면", 실주문·엑셀 |
| INV-3 | VIP → `round(after_threshold × 0.95)` | 59,400 → 56,430 |
| INV-4 | 순서: 문턱 10% → VIP 5% | 인터뷰 명시 |
| E-1 | `qty < 0` → 오류, 0원 표시 금지 | CS 클레임 |
| E-2 | `items` 없음 → 500 금지, 명시적 400 | CS 클레임 |
| AC-1 | 비VIP 03-12 장바구니 → 59,400 | 골든 케이스 |
| AC-2 | VIP 03-12 장바구니 → 56,430 | 골든 케이스 |

**보류(OOS):** 50,000원 정확히 포함 여부, qty=0, 쿠폰·배송비, VIP 단독(문턱 미달), 반올림 예외.
